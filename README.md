## Development

Prefer working locally? You need Node.js — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating). Yarn 4 is pinned in `package.json` and provided by Corepack.

```sh
git clone <this-repository-url>
cd <repository-name>
corepack enable
yarn install
yarn dev
```
